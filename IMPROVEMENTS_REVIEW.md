## Source notes

Joomla's [Web Services documentation](https://manual.joomla.org/docs/next/general-concepts/webservices/) demonstrates PATCH with introtext/fulltext and category filters. The [Joomla 4 core API reference](https://docs.joomla.org/J4.x%3AJoomla_Core_APIs) lists category, tag, field, menu, module, media and user API families. These are planning references; actual Joomla 4/5 endpoint availability, plugins, permissions and payload support must be checked for each approved feature.
